# Unclear tasks

An unclear task does not say what done looks like, so an agent would have to guess. Ask the owner first.

Vague wishes with no target: make it better, make it nicer, improve it, improve the page, polish things, clean up,
tidy up, fix it, fix this, fix the problem, sort it out, handle it, deal with it, do something about it, make it work,
make it good, make it pretty, optimise everything, check everything, look into it, look at this, have a look, see what
you can do, whatever you think is best, anything is fine, as you like.

References to something never named: that bug, the issue, the problem we saw, the thing, this thing, that part, the
other one, same as before, like before, like last time, as discussed, as we talked about, you know which, the usual,
the one from yesterday, it, this, that, there, those.

Questions instead of requests: why is it like this, what do you think, is it possible, can we, should we, any idea,
maybe, perhaps, not sure, I wonder, what about, how about.

Choices the owner has not made: which design, which colour scheme, which provider, which library, which price, which
plan, which layout, pick one, decide for me, up to you.

A single word or a title with no detail: help, update, change, review, test, idea, todo, misc, stuff, things, more,
again, continue, next.

Requests that contradict themselves, or ask for the whole product to be better without saying where or how.
