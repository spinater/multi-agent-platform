# Light tasks

A light task is ready to start: small, mechanical and obvious, in one or two files, with no design decisions. A
small, fast model is enough.

Text and copy: fix a typo, fix spelling, fix a misspelled word, change wording, reword a sentence, change a label,
change a button text, change a heading, change a title, change a placeholder, change an error message text, update a
translation string, fix a broken link, update a URL, update an email address in the footer.

Docs: update the README, add a section to the docs, fix the install instructions, add a comment, add a docstring,
update the changelog, document an option.

Small style: change a colour, change a font size, change spacing, padding or margin, align an icon, swap an icon,
change a border radius, hide an element, show an element.

Mechanical code: rename a variable, rename a function, rename a file, remove unused imports, remove dead code, fix a
lint warning, format a file, bump a version number, change a constant, change a default value, change a timeout
value, add one simple unit test, fix a failing snapshot after a text change.

Words that mark it: typo, wording, label, copy, text, rename, comment, docs, readme, colour, spacing, icon, constant,
version, lint, format, minor, tiny, small, quick, one line, simple.
