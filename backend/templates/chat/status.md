# Status questions

The owner asks how things stand and wants an answer, not a change.

What is running, what is the status, how is it going, how far along is it, is it done yet, is it finished, did it work,
did the deploy work, is the build green, are the tests passing, why did the task fail, why did it fail, what failed,
what went wrong, what happened, what changed, what changed today, what did you do, show me the progress, any errors,
any problems, how many tasks are open, which tasks are pending, what is left, what is next, what are you working on,
where are we, give me a summary, report, explain why, what does this mean, how does it work, where is the code for it,
which file, who changed it, when did it break, is anything waiting for me, anything to approve, is the deploy done,
is it deployed, is it live, is it merged, is the build passing, did the tests pass, is the server up, is it broken,
is it still running, has it finished, how long will it take.
